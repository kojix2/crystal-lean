# crystal-lean

[![CI](https://github.com/kojix2/crystal-lean/actions/workflows/ci.yml/badge.svg)](https://github.com/kojix2/crystal-lean/actions/workflows/ci.yml)

> [!IMPORTANT]
> This is an experimental project intended to test an idea. There are no plans for ongoing maintenance. All code was generated by large language models (LLMs).

Translate one Crystal method to a Lean 4 model and check proofs about the model.

## Build

- Crystal **1.22.3**, Shards, and the Crystal compiler sources.
- LLVM development libraries, libxml2, libffi, and a C/C++ toolchain.
- Lean 4 for proof checks. Python 3 for tests.

```sh
shards install --frozen
shards build --frozen
bin/crystal-lean --help
```

## Use

```sh
# Show how the tool reads the Crystal method.
bin/crystal-lean inspect examples/clamp.cr

# Write a Lean model.
bin/crystal-lean translate examples/clamp.cr -o Clamp.lean

# Check a proof.
bin/crystal-lean verify examples/clamp.cr \
  --proof proofs/clamp_correct.lean --theorem clamp_correct
```

- Add `--check` to the `translate` command above to compare `Clamp.lean` with a fresh model without writing to the file.
- Set `CRYSTAL=/path/to/crystal` if the tool cannot find the right Crystal standard library.
- Use `--lean /path/to/lean` or set `LEAN` to choose Lean. If Lean's linker conflicts with Crystal's, keep Lean's `bin` directory off `PATH` and use the full path to `lean`.

## Supported Crystal

- Write one top-level method. Give each parameter and the return value a type.
- Use `Int32`, `Bool`, and `Array(Int32)`. An array return must be one of the input arrays.
- Use local assignments, `if` and `while` with `Bool` conditions, and `return`. A final expression can also return a value.
- Use `+`, `-`, `*`, `//`, `%`, and integer comparisons. The tool also supports Boolean negation and equality, array indexing, and `size`.
- To write array elements, take one array parameter and return it. The model tracks its elements after a successful return.

## Proof checks

- Use Lean files you trust. Without a contract, `verify` reports the selected statement and its axioms. Check that the statement describes the property you want.
- To check against a contract, define a `Prop` that directly uses `crystalProgram` and add `--contract FILE --statement NAME`. See the [bubble sort contract](proofs/bubble_sort_contract.lean) and its [proof](proofs/bubble_sort_correct.lean).
- The first argument to `crystalProgram` is a limit called `fuel`. `.error .outOfFuel` means the model reached that limit before it could give a result.
- Lean checks the generated model. The translation from Crystal to Lean has no formal proof yet.

## Tests and examples

- Run `./tests/run` after `shards install --frozen`. It rebuilds the tool and runs the tests.
- Browse the [Crystal examples](examples/) and [Lean proofs](proofs/).
- [CI](.github/workflows/ci.yml) runs the tests with the latest stable Lean release.
